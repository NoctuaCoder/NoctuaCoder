*Compiling the night.*

[English](./README.md) · [Português do Brasil](./README.pt-BR.md) · [Portfolio](https://noctuacoder.github.io/NoctuaCoder/portfolio.html)

I build software that runs close to home. Noctua Lab brings together Linux desktops, local AI tools and carefully designed interfaces, with an emphasis on code you can inspect and run yourself.

## Selected projects

**Linux desktop** · [noctua-niri](https://github.com/NoctuaCoder/noctua-niri)

A Niri desktop setup with Quickshell widgets, QML components and installation scripts.

**Local AI infrastructure** · [ArbiterAI](https://github.com/NoctuaCoder/ArbiterAI)

A local runtime for coding agents with isolated Docker environments.

**Local models** · [voidkitty-llm](https://github.com/NoctuaCoder/voidkitty-llm)

Rust tooling for downloading GGUF models and running them locally with llama.cpp.

**Open-source contribution** · [termlens #178](https://github.com/vyncint/termlens/pull/178)

Added a typed error for invalid terminal sizes to a test harness for terminal applications.
